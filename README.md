
# Sadia Sultana Tanha - Personal Portfolio

## About the Project
This project is a personal portfolio website created using HTML. It introduces Sadia Sultana Tanha, her educational background, skills, hobbies, future goals, and contact information.

The website uses a green and nature-inspired theme to reflect the beauty of Sylhet's tea gardens.

## Technologies Used
- HTML5
- Inline CSS

## Website Sections
- **Home:** Name and personal introduction
- **About Me:** A short introduction
- **Education:** School, college, and university information
- **My Skills:** Personal and technical skills
- **My Hobbies:** Reading, cooking, travelling, and nature
- **My Goals:** Study plan, skill development, and future dreams
- **Contact Me:** Location and social media links

## Features
- Simple and beginner-friendly HTML structure
- Nature-inspired green color theme
- Background and multiple images
- Different heading sizes and text styles
- Horizontal lines to separate sections
- Image descriptions using the `alt` attribute
- Links to Facebook and Instagram

## Project Files
- `index.html` - Main portfolio webpage
- `bg.jpg` - Background image
- `banner.jpg` - Tea garden banner image
- `logo.png` - Personal logo
- `hobby1.jpg` - Reading books
- `hobby2.jpg` - Cooking
- `hobby3.jpg` - Travelling
- `hobby4.jpg` - Nature

## How to Run the Project
1. Download or clone this repository.
2. Make sure all image files are in the same folder as the HTML file.
3. Open `index.html` in any web browser.
4. Explore the different sections of the portfolio.
